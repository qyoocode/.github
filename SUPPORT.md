# Support

Qyoo’s public repositories are maintained by Pushplay LLC. Support is best effort;
reference and experimental code does not carry a production service commitment.

Start with the repository README, tests and documented limitations, or the
[FAQ](FAQ.md). For questions or reproducible non-sensitive defects, open an issue
in the affected repository with the revision, runtime, input and observed result.
Feature proposals should explain the intended use and scope.

For vulnerabilities, credentials or private information, follow
[SECURITY.md](SECURITY.md). Do not post them in public issues. Contributors follow
our [Code of Conduct](CODE_OF_CONDUCT.md).
